# Шкала тревоги Бека — BAI

Отдельный веб-проект для оценки выраженности тревожных симптомов за последнюю неделю и наблюдения личной динамики.

## Как работает

- 21 вопрос с четырьмя вариантами интенсивности;
- итоговая сумма от 0 до 63 и интерпретация диапазона;
- сравнение с предыдущим прохождением;
- история сохраняется только в браузере пользователя;
- отдельные записи можно удалять;
- данные не отправляются психологу или на сервер.

Результат не является диагнозом и не заменяет консультацию специалиста.

## Локальный запуск

```bash
npm install
npm run dev
```

Публичная версия автоматически разворачивается через GitHub Pages.
